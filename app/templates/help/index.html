Pusat Bantuan

?? Memulai

Selamat datang di Finance App!

Aplikasi ini membantu Anda mencatat dan mengelola keuangan pribadi dengan mudah. Berikut langkah awal:

  1. Daftar — Buat akun baru di halaman Register
  2. Setup Akun — Masukkan akun pertama Anda (Cash, Bank, atau E-Wallet) dengan saldo awal
  3. Dashboard — Lihat ringkasan keuangan Anda
  4. Catat Transaksi — Tambah pemasukan atau pengeluaran

?? Dashboard

Dashboard menampilkan:

  • Saldo Tersedia — Total uang di semua akun likuid (Cash, Bank, E-Wallet, Tabungan)
  • Total Aset
    — Nilai semua aset + investasi
  • Kewajiban — Total hutang dan saldo negatif kartu kredit
  • Net Worth — Aset dikurangi kewajiban
  • Pemasukan & Pengeluaran — Per periode (bulan ini, tahun ini, dll)
  • Transaksi Terakhir — 5 transaksi terbaru

?? Akun

Kelola berbagai jenis akun:

  • Cash — Uang tunai
  • Bank — Rekening bank (BCA, Mandiri, BNI, dll)
  • E-Wallet — GoPay, OVO, DANA, dll
  • Kartu Kredit — Dengan limit kredit
  • Tabungan — Rekening tabungan
  • Investasi — Portofolio investasi

Tip: Saldo awal bisa diubah nanti, dan saldo akan otomatis dihitung ulang dari transaksi.

?? Transaksi

Jenis transaksi:

  • Pengeluaran (Expense) — Uang keluar, saldo akun berkurang
  • Pemasukan (Income) — Uang masuk, saldo akun bertambah
  • Transfer — Pindah uang antar akun (tidak dihitung sebagai income/expense)
  • Pembayaran Hutang — Bayar hutang, saldo berkurang tapi bukan expense
  • Refund — Pengembalian uang, saldo bertambah tapi bukan income

Catatan: Setiap transaksi wajib memilih akun. Kategori opsional untuk income/expense, wajib untuk transfer.

?? Laporan

Laporan tersedia:

  • Harian — Transaksi per hari
  • Mingguan — Agregasi per minggu
  • Bulanan — Ringkasan per bulan
  • Per Kategori — Breakdown pengeluaran per kategori
  • Tren 6 Bulan — Grafik income vs expense

?? Fitur Lainnya

  • Hutang (Debts) — Catat hutang piutang, RECEIVABLE (orang utang ke Anda) atau PAYABLE (Anda utang)
  • Tagihan (Bills) — Jadwal tagihan berulang (listrik, internet, langganan)
  • Budget — Batas pengeluaran per kategori
  • Tabungan (Savings) — Target tabungan dengan progress bar
  • Aset — Catat aset berharga (mobil, rumah, elektronik)
  • Investasi — Portofolio saham/crypto/dll dengan return tracker
  • Kategori — Hirarki kategori (parent/child) untuk pengeluaran & pemasukan
  • Struk (Receipts) — Scan struk pakai OCR (Tesseract atau AI)
  • Kartu Kredit — Limit, statement date, minimum payment

?? Keamanan

  • Password di-hash dengan PBKDF2-SHA256 (600K iterasi)
  • Session disimpan di database (bukan JWT)
  • CSRF token di semua form
  • Session expired setelah 30 hari tidak aktif
  • User hanya bisa melihat data sendiri (isolasi penuh)

?? Tips

  • Gunakan Transfer untuk pindah uang antar akun — tidak mempengaruhi income/expense
  • Gunakan Pembayaran Hutang untuk bayar hutang — saldo berkurang tapi bukan expense
  • Gunakan Refund untuk pengembalian uang — saldo bertambah tapi bukan income
  • Net Worth = Aset - Kewajikan — ini ukuran kekayaan bersih Anda
  • Saldo akun = Saldo awal + Income - Expense - Transfer keluar + Transfer masuk

?? Menu Admin

Jika Anda adalah admin, akses panel admin di sidebar untuk:

  • Melihat statistik sistem (total user, transaksi, akun)
  • Mengaktifkan/menonaktifkan akun user
  • Memberikan/mencabut hak admin

Login Admin: Set user sebagai admin via environment variable AUTH_BOOTSTRAP_USERNAME atau via database.
